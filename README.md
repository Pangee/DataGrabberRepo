# DataGrabber

County property lookup for macOS.

## Download

Get **DataGrabber 1.0** from [Releases](https://github.com/Pangee/DataGrabberRepo/releases/tag/v1.0).

Requires macOS 15 or later on Apple Silicon.

1. Download `DataGrabber.dmg`
2. Open the disk image and drag **DataGrabber** into **Applications**
3. If macOS already has a copy, choose **Replace**
4. Open DataGrabber from Applications

The first time, macOS may block the app because it is not signed with an Apple Developer ID. Right-click DataGrabber, choose **Open**, then **Open**.

## Version

The app is always named `DataGrabber.app`, so installing a newer release replaces the one in Applications. The version is on the GitHub Release and inside the app at `Contents/Resources/VERSION.txt` (Show Package Contents).
